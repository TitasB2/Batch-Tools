# Batch Tools
Batch Tools short for BT is a batch file that has cmd commands.

## ⚠️ Safety warning

`BT` includes commands that can **immediately**:

- Log you out
- Lock your PC
- Put your PC to sleep or hibernate
- Shut down or restart your computer

These commands are marked with `*` in the built‑in `help` output (`* – didn’t test yet`).  
Use them only if you understand what they do, and **do not run this script as Administrator** unless you specifically need extended system information.

If you’re unsure, avoid using any command that mentions *logout*, *shutdown*, *restart*, *hibernate*, *lock*, or *sleep*.
